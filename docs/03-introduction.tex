\chapter*{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

Растения имеют основополагающее значение для экосистем Земли и жизни человека, играя незаменимую роль в поддержании и улучшении глобального экологического баланса. Методы распознавания образов и обработки изображений используются для автоматизации классификации растений, что позволяет снизить трудоёмкость определения вида и расширить возможности анализа ботанических данных~\cite{ref1101}.

Цель работы~---~разработать метод классификации растений по изображениям листьев с использованием свёрточной нейронной сети.

Задачи, которые нужно реализовать для достижения поставленной цели:
\begin{enumerate}[itemsep=0pt, parsep=0pt, topsep=0pt]
	\item провести анализ предметной области с целью выявления проблем в задачах таксономизации растений;
	\item формализовать задачу для проведения классификации изображений листьев растений средней полосы России;
	\item разработать двухэтапный метод классификации растений по изображениям листьев с использованием свёрточной нейронной сети;
	\item разработать алгоритмы для реализации предложенного метода;
	\item реализовать программу на основе разработанного метода;
	\item сравнить результаты расчётов по разработанному методу с результатами классификации после прямого обучения.
\end{enumerate}
