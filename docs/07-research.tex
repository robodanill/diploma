\chapter{Исследовательский раздел}

Целью исследования является оценка качества и вычислительных характеристик разработанного метода классификации изображений растений. Для сравнения используются показатели точности классификации и время классификации одного изображения.

\section{Сравнение разработанного метода с базовым}
Для оценки разработанного метода выполняется сравнение с базовыми подходами, основанными на прямом обучении модели VGG16 для многоклассовой классификации видов растений.

Исходная выборка отсканированных листьев содержит 12\,605 изображений. Сформированное подмножество для обучения S-CNN имеет 43 рода, 60 видов и 360 изображений. Тестовая выборка содержит 221 изображение, 43 рода и 60 видов.

Для оценки влияния числа родов-кандидатов на итоговое качество было рассмотрено изменение точности при варьировании параметра отбора родов и числа эталонных изображений. \section{Вывод}
В исследовательском разделе выполнено сравнение разработанного метода с прямым обучением свёрточной нейронной сети. Разработанный метод даёт умеренное повышение точности на ограниченной обучающей выборке, при этом сохраняет преимущество метрического подхода: для добавления новых эталонных изображений не требуется переобучать классификационный слой. Увеличение времени классификации связано с последовательным использованием двух моделей и эталонного индекса.
