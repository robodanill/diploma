\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

В ходе выполнения выпускной квалификационной работы была достигнута поставленная цель~---~разработан метод классификации растений по изображениям листьев с использованием свёрточной нейронной сети.

Для достижения цели были решены следующие задачи:
\begin{itemize}[label=---, itemsep=0pt, parsep=0pt, topsep=0pt]
	\item проведён анализ предметной области классификации изображений растений;
	\item формализована задача классификации изображений растений;
	\item разработан метод классификации растений по изображениям листьев с использованием свёрточной нейронной сети;
	\item выполнено сравнение разработанного метода с существующими методами.
\end{itemize}

В рамках работы рассмотрены особенности изображений растений и факторы, влияющие на качество распознавания, включая визуальную схожесть видов и ограниченность обучающих данных. На основе анализа существующих подходов был выбран метод, использующий двухэтапную иерархическую классификацию: на первом этапе выполняется отбор родов по глобальному представлению изображения листа, на втором этапе уточняется вид растения с использованием локального представления.

Разработанный метод реализован в виде программного приложения, поддерживающего загрузку изображений, формирование эталонного индекса и получение ранжированного списка наиболее вероятных видов растений. Проведённые эксперименты показали применимость предложенного подхода для задачи классификации растений по изображениям листьев и позволили сравнить его с базовым подходом прямого обучения VGG16.
