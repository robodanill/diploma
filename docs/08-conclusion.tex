\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}
В ходе выполнения научно-исследовательской работы был проведён анализ методов классификации изображений растений и выполнены следующие задачи: 
\begin{itemize}[label=---]
	\item проведён анализ предметной области классификации изображений растений;
	\item формализована задача классификации изображений растений;
	\item описаны существующие методы классификации изображений растений;
	\item определены критерии сравнения методов классификации изображений растений и проведено сравнение.
\end{itemize}
